# ClothingERP Backups website

Public product information, privacy policy and terms for the ClothingERP Backups Google OAuth application. No application credentials, business data or backups belong in this repository.

## Publish

In repository Settings > Pages, select Deploy from a branch, then main and /(root). Save. The intended homepage is https://ashutosh-dhawan2003.github.io/clothingerp-website/ with privacy.html and terms.html alongside it.

Confirm all three URLs load before entering them in Google Auth Platform > Branding. Publication of this site does not itself verify the Google OAuth app. Complete any ownership verification or other requirements Google requests.

This site uses local CSS, no JavaScript and no third-party fonts or analytics. Support contact: ashutoshdhawan012003@gmail.com.
